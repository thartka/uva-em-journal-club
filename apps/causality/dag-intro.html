3: Drawing DAGs

← Back to Module

A directed acyclic graph (DAG) is a picture of causal assumptions. Each node is a variable; each arrow means “this may cause that.” Drag from one node to another to draw an arrow.

Exercise 1: Smoking and cancer

Drag from one node to the other to show which variable you think causes the other.

Drag from one node to the other to draw a causal arrow.

Exercise 2: Add inflammation

Draw arrows among all three nodes. Try a mediator chain (Smoking → Inflammation → Cancer), then clear and try pointing both Smoking and Cancer into Inflammation.

Drag between nodes to draw arrows. Try building Smoking → Inflammation → Cancer, or draw both Smoking and Cancer into Inflammation.

Takeaway: The same variables can be arranged into different causal stories. A mediator lies on the pathway; a collider is where two arrows meet.
