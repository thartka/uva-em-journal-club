  • Type I error (α): a false positive, claiming an effect that isn’t real. You set this directly with the significance level (α = 0.05 means a 1-in-20 false-positive rate).
  • Type II error (β): a false negative, missing an effect that is real. Power = 1 − β is the chance of catching it.
  • α and sample size do different jobs: α fixes the Type I error rate. A bigger trial does not lower it. Sample size drives the Type II error rate (β) down, raising power.
  • Statistical ≠ clinical significance: a big enough trial can make a trivial difference “significant.” Read the effect size and its confidence interval, not just the p-value.
  • The absence of evidence is not the evidence of absence: a negative trial may be underpowered (Type II), not truly negative. Check whether it could have detected a meaningful effect.
